## What we covered

- The course: materials on GitHub, the program, the course project.
- VSCode: text editor vs IDE, the command palette (`Ctrl+Shift+P`), DevTools.
- Git and GitHub: `git init`, `git status`, `git add`, `git commit -m`,
  `git config`, `git remote`, `git push`; Source Control in VSCode.
- JavaScript: what it is, its history (ECMAScript, JSON), JavaScript engines,
  the DevTools console, Node.js.
- Running JavaScript in the browser (`<script>`) and with Node.js in the terminal.
- How a program runs: machine code, compiler vs interpreter, V8.
- Program structure; variables, values and memory.

We stopped at **declaring and defining variables**, so the
[next lecture](/lectures/02-variables-and-types) starts there.

## Homework from session 1

1. Follow the [setup instructions](https://ivapopova-courses.github.io/JS-TS-Basics-Slides/pages/themes/SetupCourseEnvironment/SetupCourseEnvironment.html#/).
2. Create a GitHub account for the course (if you do not have one).
3. Create a local git repository for your homework, with a `script.js`
   (`console.log('Hello')`), and push it to GitHub.
4. Get to know VSCode.
5. Think about the course project.
